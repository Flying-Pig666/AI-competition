## 摘要

上市公司风险暴露之前,公告与财报中早已埋下信号:控股股东高比例质押、利润与现金流背离、非经常性损益粉饰……但公告以非标准化 PDF/扫描件发布,人工阅读难以规模化监控。

本项目构建"**驼研·信鉴**"智能体:从公告与财报中**提取**多源结构化数据(选题一),用代码**算准**每一项财务指标(选题二),以红旗规则引擎**预警**信用风险,并做到每一个数字都可溯源到原文证据、每一步执行都可追溯复现。

**当前已完成可运行原型**:质押公告提取在三份真实样本上通过全部一致性校验(12/12、11/11、12/12),原文溯源覆盖率文本件 100%;财务预警引擎对康美药业的回溯测试中,提前于爆雷 1-2 年识别出"利润与现金流背离"等红色信号;对贵州茅台、贵阳银行等健康标的零误报。

## 一、项目背景与痛点

### 1.1 业务痛点

1. **公告非结构化**:质押、中标、股权变动等关键公告以 PDF/扫描件发布,格式千差万别,关键字段(股东、股数、比例、日期、质权人)散落在正文与复杂表格中,人工提取慢、易错、无法规模化。
2. **财报分析门槛高**:同比/环比计算、非经常性损益识别、会计口径变化、利润与现金流背离等分析需要专业训练,普通投资者与基层风控人员难以完成。
3. **风险发现滞后**:股权质押爆仓、财务造假等风险事件,其先兆信号(高质押比例、存贷双高、利润含金量下降)在公开材料中早已存在,但缺乏自动化工具将其串联成预警。
4. **AI 回答不可信**:通用大模型直接回答金融问题存在幻觉,数字无法溯源,不满足投研场景的严谨性要求。

### 1.2 真实案例:康美药业的教训

康美药业 2019 年爆出 300 亿货币资金造假案,震惊市场。但回溯其公开财报:**2018 年报净利润 3.74 亿元,每股经营现金流却已为 -0.64 元**;2017 年净利润与扣非净利润差异率高达 87%。这些信号均早于监管立案与市场崩盘。如果存在自动化工具持续监控这些信号,风险本可被提前发现。本项目即以此为出发点。

## 四、核心技术方案

### 4.1 多源文档解析(数据层/解析层)

- **文本层 PDF**:pypdf 抽取全文,pdfplumber 解析表格结构,处理多级表头纵向拼接;
- **扫描件**:PyMuPDF 渲染页面 → RapidOCR 识别 → 按行框坐标重建表格结构;
- **自动判别**:文本层过少的页面自动判定为扫描页并切换 OCR 通道。

### 4.2 LLM 结构化提取 + 校验-重试闭环(提取层)

- 国产大模型(主力 DeepSeek,备用 Kimi,均为 OpenAI 兼容协议),少样本 Prompt 约束 JSON 输出;
- **校验-重试闭环**(自研,参考 Instructor 模式):每轮输出先经 Schema 强校验 + 业务规则校验(证券代码格式、记录类型枚举、股数为正整数、比例值域 [0,100]、质押类公告记录非空),不通过则将**问题清单回灌给模型修正**,最多 3 轮,全程留痕;
- 规则提取路径作为兜底与交叉参照,任何单一环节失效都不影响系统整体可运行。

### 4.3 三层校验体系(校验层)——对应"结果一致性"

1. **Schema 合规校验**:pydantic 强类型,杜绝格式错误;
2. **跨字段勾稽校验**(6 类):记录类型完整性、累计质押勾稽(质押后=质押前−解除+新增)、占其所持比例勾稽、占总股本勾稽(总股本由持股比例反推)、风险提示勾稽、合计行加总/加权勾稽;
3. **原文溯源校验**(自研 `grounding.py`):每个已提取字段的值逐页回原文搜索证据,标注页码;找不到证据的字段显式标记"未溯源"并提示人工复核 —— 既控幻觉,又控误报。

### 4.4 确定性指标计算 + 双源数据采集(数据层/分析层)

- 财务数据经 akshare 公开接口采集(同花顺财务摘要 + 新浪财务指标双源),落盘 CSV 并生成采集元数据(来源、时间、行数),**演示不依赖实时网络**;
- 同比、环比、比率等指标全部由 Python 代码计算,LLM 只做归因叙述 —— 这是"计算准确性"的工程纪律。

### 4.5 红旗规则引擎(预警层)

| 编号 | 规则 | 触发逻辑(摘要) | 对应竞赛考点 |
|---|---|---|---|
| R1 | 利润与现金流背离 | 净利润>1000万 且每股经营现金流<0 | 利润与现金流背离 |
| R2 | 非经常性损益占比异常 | \|净利润−扣非\|/\|净利润\|>30% | 非经常性损益 |
| R3 | 营收与利润背离 | 营收降且利润增,增速差>30pp | 异常信号 |
| R4 | 业绩变脸 | 净利润同比降幅>30%/50% | 业绩变化原因 |
| R5 | 持续亏损 | 连续两年净利润为负(ST 风险) | 异常信号 |
| R6 | 高杠杆 | 资产负债率>60%/70%(银行豁免) | 偿债能力 |
| R7 | 利润含金量不足 | 每股经营现金流/每股收益<0.3 | 利润质量 |
| R8 | 股东高比例质押 | 质押占其所持>50%/70% | **选题一→二咬合点** |
| R9 | 质押到期压力 | 未来半年到期融资余额>0 | 短期偿付风险 |

R8/R9 的输入直接来自选题一的公告提取结果 —— **提取不是终点,而是预警的输入**,两个选题形成"提取→分析→预警"一体化闭环。

### 4.6 全程可追溯(日志层)

每份公告/每次分析生成 `trace.jsonl`:文件访问、解析方式、OCR 过程、工具调用、LLM 请求与响应(含 token 用量)、校验结论、溯源结果、结果落盘,逐事件记录,满足"数据来源可核验、执行过程可追溯、运行结果可复现"。

## 五、创新点

1. **选题一体化闭环**:多数参赛作品将选题一、二割裂作答;本项目让选题一的结构化提取结果(质押比例、到期压力)直接驱动选题二的风险预警,形成"公告 → 数据 → 信号 → 预警"完整价值链。
2. **三层校验 + 原文溯源的抗幻觉体系**:不止于"输出 JSON",而是让每个字段可回原文定位页码,未溯源字段显式标记人工复核 —— 直接回应金融场景对幻觉的零容忍。
3. **校验-重试闭环的格式保证**:LLM 输出不合格即携问题清单自动重试,格式规范性由"祈祷模型"变为"工程闭环"。
4. **行业口径豁免机制**:银行业等特殊行业的现金流、杠杆口径自动豁免相应规则,体现金融专业性,避免教科书式误报。

## 七、评测方案(字段级量化自证)

1. **评测集构建**:采集工具已实现(`eval_collect.py`,从巨潮资讯网检索下载,元数据留痕)。
   **首轮已采集 10 份未见质押公告并完成批量评测**(`eval_run.py`):
   - 10/10 全部跑通(LLM 路径),平均原文溯源覆盖率约 90%;
   - 4 份样本全部校验通过,其余多仅差 1-2 项;
   - **校验机制主动发现 2 例提取偏差**(一致行动人合并披露口径差异、累计质押数字误植)——
     证明三层校验不是摆设,而是能抓真问题的质量闸门;
   - 预告/拟签署类公告(无累计质押表)已识别为"勾稽不适用",不误报。
2. **指标**:字段级精确率/召回率/F1(参照 FinReasoning 的 F1-Score(Field) 口径),
   勾稽校验通过率,溯源覆盖率,误报率;
3. **双模型对照**:DeepSeek 与 Kimi 双线路并行评测,验证模型无关性;
4. **时序合规**:风险回溯测试严格用 T 期及以前数据预测 T+1 期风险,杜绝前视偏差;
5. **下一步**:评测集扩充至 30 份并人工标注 Gold Standard,覆盖中标、股权变动类型。
